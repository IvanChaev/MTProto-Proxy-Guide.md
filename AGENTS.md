# ОБЯЗАТЕЛЬНОЕ ПРАВИЛО: универсальность программы на GitHub
Нейросетевой агент обязан сохранять на GitHub универсальность программы — она должна запускаться и работать на ЛЮБОМ компьютере.
Запрещается пушить на GitHub жёстко зашитые пути конкретной машины (например, `D:/ProgramData/.cache/huggingface`, `D:\programs\python3.11.8\pythonw.exe`) и другие машинно-зависимые настройки.
На GitHub допустимы только переносимые решения: стандартный кэш Hugging Face / переменная окружения `HF_HOME`, поиск `pythonw.exe` через PATH (`shutil.which`), универсальные скрипты и настройки.
Локальная рабочая копия может содержать машинно-специфичные правки, но на GitHub они попадать не должны.

Для push: клонировать репозиторий во временную папку, скопировать изменённые файлы из локальной папки, закоммитить и запушить.
